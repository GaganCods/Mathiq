## 🚀 Features

Mathiq is built to handle everything from daily math to complex financial formulas:

- 🧮 **Basic Calculator** — Essential arithmetic with history tracking.
- 🔬 **Scientific Calculator** — Advanced trigonometric and logarithmic functions.
- 💱 **Currency Converter** — Real-time comparable exchange rates.
- 📊 **Percentage Calculator** — Quick margin and discount computations.
- ⏱️ **Age Calculator** — Precise date and age differences.
- ⚖️ **BMI Calculator** — Health tracking with actionable insights.
- 📱 **Responsive Design** — Flawless experience across all devices.
- 🌙 **Dark Mode** — Premium, developer-first dark aesthetic.
- ⚡ **Fast Performance** — Instantaneous calculations without lag.
- 🔍 **SEO Optimized** — Structured for discoverability and scale.
- 📱 **Mobile Friendly** — Built touch-first for on-the-go usage.
- 🎨 **Smart UI/UX** — Modern bento grids and minimal visual noise.

## 🛠️ Installation

To run Mathiq locally on your machine, follow these steps:

```bash
# Clone the repository
git clone https://github.com/GaganCods/mathiq.git

# Navigate into the project directory
cd mathiq

# Open the project
open index.html
```
